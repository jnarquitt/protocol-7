# Protocol 7 — Runbook

## Start of Work
1. Read `CLAUDE.md` and all `.jade-lion/*.md` state files.
2. Confirm the active branch and latest commit before changing files.
3. Identify the authoritative source file for the active task.
4. Preserve existing revisions unless replacement is explicitly authorized.

## Adventure Content Workflow
1. Recover the currently promoted mission from `continuance-files/current.html`.
2. Read the full current GM guide, relevant player briefing, apocryphon, campaign continuity, and current Protocol 7 rules target.
3. Make new revisions rather than overwriting archival revisions.
4. Apply Jade Lion/ZPA design requirements without silently changing mechanics.
5. Validate HTML structure, navigation, links, print behavior, and current-page promotion.
6. Verify the committed file and current page on the intended branch.

## Rules Changes
Never retarget a mission to a newer Protocol 7 rules version without a mechanics audit. Record the audit in `.jade-lion/STATE.md` and update affected content deliberately.

## Branding
Use the locked Jade Lion colored-pencil/paper house style for flagship presentation. Utility marks may be simplified but must remain derived from the same identity.

## GitHub
Use GitHub as persistent project truth. Record consequential creative, product, mechanics, workflow, and release decisions in `.jade-lion/DECISIONS.md`.

## Stop Conditions
Stop and report rather than improvising if a requested change would:
- alter mechanics outside the agreed scope;
- overwrite a historical revision;
- contradict a locked decision;
- require an unavailable binary/toolchain workflow;
- materially redesign an adjacent product without approval.
