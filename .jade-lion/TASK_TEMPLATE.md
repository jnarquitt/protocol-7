# Jade Lion Task Template

## Objective
Describe the exact outcome to produce.

## Authoritative Files / State
List the files, branch, revision, and state documents that control the task.

## Allowed Scope
State exactly what may change.

## Preserve
List adjacent behavior, visuals, mechanics, content, and revisions that must remain unchanged.

## Acceptance Criteria
Define observable completion conditions.

## Validation
List required structural checks, link checks, visual review, rules audit, build/test evidence, or publication verification.

## Repository Updates
Update `.jade-lion/STATE.md`, `.jade-lion/DECISIONS.md`, `.jade-lion/RELEASE.md`, or other state files when the task changes persistent truth.

## Delivery
Commit to the intended branch and verify the expected remote commit/files.

## Stop / Report Conditions
Stop rather than improvise if scope would expand, a locked decision conflicts, authoritative state is missing, or a required toolchain is unavailable.
