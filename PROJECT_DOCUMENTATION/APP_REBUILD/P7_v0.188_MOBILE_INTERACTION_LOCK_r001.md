# Protocol 7 v0.188 — Mobile Interaction Lock r001

**Status:** LOCKED IMPLEMENTATION REQUIREMENT
**Date:** 2026-08-23
**Applies to:** v0.188 Vector App rebuild and promotion QA

This lock supplements the Application Requirements Bible and has authority over implementation details where the earlier document is less specific.

## Core interaction law

Protocol 7 is a phone-first table-play application. Except for entering the Vector's name, normal character creation, advancement, equipment selection, VAM management, and gameplay shall not require keyboard typing.

Mechanical choices are tap/select operations. Spendable quantities and purchases use large + / − controls, steppers, toggles, cards, die pickers, or similarly obvious touch controls. A player must be able to create and operate a legal Vector with touch alone after entering the name.

## Required behavior

- **Vector Name:** free typing is allowed and expected.
- **Concept/background/identity:** must not require typing. Use selectable/preconfigured choices where mechanically or product-relevant; optional prose notes must never block play.
- **Abilities:** assign with tappable die cards/selectors. Enforce the starting d8, d8, d6, d6, d4, d4 multiset automatically.
- **Skill Ranks:** purchase/refund with large + and − buttons. Show current rank, current Skill die, spent ranks, and remaining budget live. Do not use numeric inputs.
- **Vitality Ritual:** provide a ROLL control for each Ability and/or a physical-dice face picker. Do not require six typed numeric results.
- **HP:** routine damage/healing uses large +/− controls and useful common increment buttons; no numeric keyboard required.
- **AP:** represent three AP as tappable units or equivalent direct controls; no dropdown/numeric entry for ordinary use.
- **Reaction:** one-tap Available/Used control.
- **Conditions:** tappable cards/chips/toggles.
- **VAMs:** browse by family, authorization, loaded state, presets, and other touch filters. Search may exist only as optional convenience. Loading/unloading is a tap. BAR updates immediately.
- **Gear:** select from catalog/cards; quantities use +/- controls. Gear creation by typing is not part of ordinary player workflow.
- **Advancement:** Level/Edge/Ability increases/Mastery are selected by tap. Skill Rank grants are spent with +/- controls.
- **Rolls:** Skill, situational state, Gear, VAM, Advantage/Disadvantage, Mastery access, and other sources are selected/toggled; no typed modifier or die source.
- **Import/export:** player-facing builds use button/file/share mechanisms where possible. Raw JSON textarea may exist only in explicitly marked developer builds.

## Prior-app continuity

The v0.187 app remains the known-good feature and interaction reference. Successful prior functionality, automation, preconfigured-character behavior, and low-friction table controls are to be preserved or improved unless they conflict with v0.188 mechanics or a newer locked requirement.

The rebuild is not permission to replace useful game-app controls with generic HTML forms.

## Mobile QA gate

A release candidate fails the mobile usability gate if any of the following is true:

- Skill Rank purchase requires keyboard entry.
- HP or AP routine adjustment requires keyboard entry.
- Vitality Ritual requires typing results.
- VAM or gear selection requires typing/searching.
- Advancement requires typed numeric values.
- Routine rolls require typing any source or modifier.
- Any required touch target is impractically small for phone use.
- A legal Vector cannot be created and played after entering the name without reopening the software keyboard.

## Immediate rebuild direction

The current r002 development shell contains temporary form controls that violate this lock (numeric Skill inputs, typed concept/gear fields, typed search as a prominent catalog control, numeric HP, dropdown AP, and raw JSON transfer). They are development scaffolding only and must be replaced before promotion.

Next implementation passes shall prioritize:
1. touch-first creation wizard and preconfigured Vector path;
2. +/- Skill Rank purchasing;
3. automated Vitality Ritual and face picker;
4. touch HP/AP/Reaction/Condition controls;
5. VAM family/preset browsing with optional search secondary;
6. selectable Gear catalog and quantities;
7. touch advancement controls;
8. restoration of successful v0.187 automation and table-play conveniences.
