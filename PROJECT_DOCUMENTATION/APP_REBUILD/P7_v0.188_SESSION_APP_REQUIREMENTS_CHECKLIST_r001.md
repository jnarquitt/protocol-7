# Protocol 7 v0.188 — Session App Requirements Checklist r001

**Purpose:** The app is primarily a teaching and demonstration tool for manual character creation, while also being fast enough to use at the table. Each implementation pass must report this checklist as COMPLETE / PARTIAL / NOT STARTED / DEFECT.

## A. Core product / usability
- A01 Mobile portrait first; large touch targets; no required horizontal scrolling.
- A02 Only Vector name requires typing during ordinary use.
- A03 Persistent, obvious navigation.
- A04 Local autosave.
- A05 Clear reset/new-character control with confirmation.
- A06 Preserve a stable fallback link to the prior v0.187 app while v0.188 is in playtest development.
- A07 App visibly teaches what each choice changes; it must not merely collect values.

## B. Starting character workflow
- B01 First screen offers **Choose Preconfigured Vector** or **Build Custom Vector**.
- B02 Preconfigured Vector cards describe role, assignment type, strengths, and likely use.
- B03 Selecting a preconfigured Vector immediately populates a complete legal starting character.
- B04 Preconfigured characters remain editable; they demonstrate character creation rather than acting as locked classes.
- B05 Provide a broad starting roster spanning: long-term embedded operator; investigator/intelligence specialist; social/cover specialist; scientist/analyst; engineer/technical specialist; medic; scout/recon specialist; close-combat specialist; ranged tactical specialist; emergency rescue/support specialist; command/coordinator; survival/archaic-era specialist.
- B06 Custom creation enforces d8,d8,d6,d6,d4,d4 and 20 Skill Ranks.
- B07 App explains why a preconfigured character received its Ability and Skill choices.

## C. Vitality Ritual / physical-dice parity
- C01 Vitality can be completed with **physical dice** by tapping the face actually rolled.
- C02 Vitality can be completed with an in-app **ROLL** button for each Ability.
- C03 Every Ability row visibly presents legal face buttons 1 through that Ability die maximum.
- C04 App marks 1–3 as blanks and 4+ as contributing faces.
- C05 App derives 18 + highest qualifying face; all-six-blanks = 28.
- C06 Tied highest qualifying Abilities require selectable Vitality Origin.
- C07 App explains what HP/Vitality represents and what the Ritual is teaching.

## D. Skills / teaching
- D01 All 40 canonical Skills are available.
- D02 General / Combat / Defense filtering or grouping prevents one giant undifferentiated list.
- D03 Plus/minus rank allocation; no typing.
- D04 20-rank starting budget enforced.
- D05 Skill die visibly updates at breakpoints and caps at d12.
- D06 Every Skill shows its three Ability dice, including intentional repeated Abilities.
- D07 Tapping/selecting a Skill can show what the resulting core roll pool looks like.

## E. Era-spanning Gear
- E01 Gear catalog supports assignments from ancient/BC periods through contemporary eras.
- E02 Archaic weapons include at minimum: knife/dagger, club, spear, sling, bow, crossbow, sword, axe, shield.
- E03 Black-powder / early-firearm support includes representative pistol and long gun.
- E04 Industrial/modern catalog includes revolvers/pistols, shotguns, rifles/carbines, automatic weapons and precision weapons.
- E05 Armor/protection includes era-appropriate categories without pretending all armor is interchangeable.
- E06 Tools/support include medical, intrusion, investigation, technical, survival, recon, cover/identity, currency/reference support.
- E07 Gear can be filtered by broad era and category.
- E08 Gear is concrete capability; normally one primary relevant Gear die enters a roll; weapons do not add a second universal damage die.

## F. VAM / BAR
- F01 Full Level-1 VAM choice needed for starting characters, not an arbitrary tiny subset.
- F02 BAR meter and 16-BAR Level-1 enforcement.
- F03 VAM cards show BAR, family, and concise effect.
- F04 Preconfigured Vectors include editable VAM loadouts.
- F05 Loading into unused BAR is free; field swap rule is clearly distinguished from character setup.

## G. Roll teaching / physical-dice parity
- G01 Player can choose **physical dice** or **ROLL** for ordinary checks.
- G02 Before rolling, app visibly constructs Skill + 3 Ability dice.
- G03 Gear, VAM, Advantage/Disadvantage and later Mastery are visibly separate named sources.
- G04 Advantage adds d6; Disadvantage removes smallest Ability die; no generic bonus slot.
- G05 Physical-dice mode can display the exact pool without forcing the app to roll it.
- G06 Digital roll shows every die result and total; 1–3 visibly count as blanks.
- G07 Difficulty reference 8/12/16/20/24 and margin bands available near roller.

## H. Table play
- H01 HP current/max controls.
- H02 3 AP controls.
- H03 Movement reference is 30 ft per AP, repeatable to 90 ft; no universal Run multiplier.
- H04 Reaction: banked AP first, otherwise borrow at most 1 next-turn AP.
- H05 Six core Conditions selectable.
- H06 Active-defense / winning-margin damage reminder available.

## I. Preconfigured assignment doctrine
Starting roster must represent mission needs, not fantasy classes. Templates are editable examples of how the same engine supports different operational durations and historical environments.
- I01 Deep Cover / Long-Term Embedded — months/years in one era; Culture, Deception, Tradecraft, Influence, period survival.
- I02 Investigator / Historical Intelligence — evidence, history, perception, investigation.
- I03 Social Infiltration / Negotiator — cover identity, culture, influence, deception, leadership.
- I04 Science / Analysis — science, medicine or investigation, technical interpretation.
- I05 Engineering / Technical — engineering, computing, security, fabrication/interface support.
- I06 Field Medic — medicine, perception, survival, recovery.
- I07 Recon / Scout — stealth, perception, survival, tradecraft, mobility.
- I08 Tactical Ranged Support — emergency insertion, sidearms/longarms/automatic weapons, dodge/reflex/tactics.
- I09 Close Protection / Extraction — unarmed/grappling/melee, athletics, dodge, rescue-oriented VAMs.
- I10 Emergency Mission Rescue — broad tactical/medical/technical competence intended to stabilize another team's failing operation.
- I11 Command / Coordinator — leadership, tactics, influence, perception, team-support VAMs.
- I12 Archaic-Era Field Specialist — Culture, History, Survival, Athletics plus bows/thrown/melee capability and era-appropriate gear.
