# Protocol 7 v0.187 — Canonical Playtest Locks

**Status:** ACTIVE PRE-BETA LOCK SET  
**Supersedes:** v0.181 playtest lock set  
**Promotion date:** 2026-08-21

These rules were audited against the v0.187 live player build and remain frozen for playtest. This promotion records continuity; it does not rebalance them.

## Frozen mechanics
- Protocol Dice: roll the complete pool once; 1–3 are blank; each 4+ scores at face value.
- Each Skill uses its defined three Ability dice; repeated Ability dice are intentional.
- Untrained Skill die is d4.
- Skill progression uses cumulative breakpoints with Progress Ranks between breakpoints.
- Starting Ability array: d8, d8, d6, d6, d4, d4.
- Starting Skill Ranks: 20.
- HP = CON die maximum × 3: d4 12, d6 18, d8 24, d10 30, d12 36.
- 3 AP per turn.
- Normal Attack = 1 AP; multiple normal attacks are permitted by paying 1 AP each unless a specific rule overrides.
- Move = 1 AP for up to 30 feet and may be repeated; there is no universal Run action in this canonical baseline.
- One normal Reaction between turns.
- Reaction spends banked unspent AP first; only if none remains may it borrow at most 1 AP from the next turn.
- One primary relevant gear die per roll unless a rule explicitly permits stacking.
- Armor normally adds its listed gear die to an appropriate defense pool; it does not also reduce damage unless explicitly stated.
- Standard active BAR capacity = 16; BAR is capacity, not energy.
- Loading a VAM into unused BAR capacity is free; field replacement/unloading costs 1 AP for the whole reconfiguration unless a specific rule overrides.
- Historical Carrier states: Fragile → Established → Durable.
- Carrier strength and Exposure are intentionally competing mission objectives.
- Mission outcomes remain Clean Success, Exposed Success, Contained Failure, and Exposed Failure.

## Playtest discipline
Do not rebalance these from a single anecdote. Record observations first and classify them as blocker, major, minor, or polish. If a proposed change touches a frozen mechanic, identify the lock and obtain explicit owner direction to unlock that exact rule before changing it.
