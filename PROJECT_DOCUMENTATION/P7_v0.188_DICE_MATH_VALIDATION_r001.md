## Advantage / Disadvantage

The r001 playtest rule adds one d6 for Advantage and removes the smallest Ability die for Disadvantage.

A d6 Advantage adds 2.50 expected Protocol points. If the smallest relevant Ability is d6, Disadvantage removes exactly 2.50 expected points, making the two effects symmetric in expectation. If the smallest Ability is d4, Disadvantage removes 1.00 expected point. If the lowest Ability has grown to d8, it removes 3.75 expected points.

This means Disadvantage is intentionally less punishing to pools containing a weak d4 Ability and more punishing to uniformly strong Ability sets. That behavior is acceptable for v0.188 playtest but is specifically flagged for observation.

Default A/D does not stack. This prevents tactical narration from inflating a normal four-die Skill pool into an uncontrolled large pool and keeps Gear, VAM, and Mastery investments mechanically distinct.

## Vitality Ritual exact enumeration

Starting Ability multiset: d8, d8, d6, d6, d4, d4.

Total equally likely face combinations: **36,864**.

Rule: if any die is 4+, HP = 18 + highest qualifying face. If all six are blanks, HP = 28.

| Starting HP | Probability |
|---:|---:|
| 22 | 9.13% |
| 23 | 16.02% |
| 24 | 29.12% |
| 25 | 20.31% |
| 26 | 23.44% |
| 28 (all blanks) | 1.98% |

Mean starting HP: **24.41**.

The all-six-blanks event occurs in 729 of 36,864 combinations, or **1.98%** (about 1 in 50.6 characters). It is rare but not so rare that a long-running playtest community will never see it.

The ordinary distribution is concentrated in the intended 22–26 band, with no ordinary low-roll character below 22 HP. The exceptional all-blanks result converts the otherwise worst possible ritual into a memorable high-HP result without materially increasing the average.

## Validation conclusion

**PASS FOR PLAYTEST.**

The Vitality Ritual has a controlled starting range and a visible rare event. The proposed A/D rule has a known, explainable expected-value profile and is suitable for table testing. Neither conclusion claims final balance; both are approved for v0.188 observation and later revision from actual play.
