# Protocol 7 v0.188 — App Advancement Synchronization Pass 01 r001

**Status:** CANDIDATE IMPLEMENTATION — Auditor review pending
**Date:** 2026-08-23

## Implementation strategy

The first v0.188 player-facing candidate intentionally does not overwrite the v0.187 known-good app. `Protocol_7_v0.188_Interactive_Character_and_Play_App_CANDIDATE.html` loads the released v0.187 HTML and applies `Protocol_7_v0.188_Advancement_Candidate_Patch.js` at runtime.

This keeps unrelated v0.187 behavior intact and isolates new advancement state under its own browser-storage key.

## Candidate UI implemented

A new **Advancement** tab provides:

- Level 1–6 selection;
- automatic BAR display: 16 / 18 / 21 / 24 / 27 / 30;
- authorization display: Standard / Advanced I / High Integration / Advanced II-Mastery / Elite / Continuance;
- six-entry Vitality Ritual recorder;
- automatic ordinary starting HP calculation: 18 + highest Ability face;
- all-six-blanks exception: 28 starting HP;
- automatic +4 maximum HP per later Level;
- Durable Edge +5 maximum HP handling;
- Level 2 Edge selection;
- Level 3 and Level 5 Core Growth recording with d12 ceiling;
- Level 4 first Mastered Skill;
- Level 6 second Mastered Skill;
- advancement/playtest notes;
- candidate-only reset.

## State isolation

Candidate advancement data uses a separate browser-storage key and therefore does not intentionally overwrite existing v0.187 saved-character state.

## Known limitation of Pass 01

This is a **runtime candidate patch**, not yet the final monolithic v0.188 app source. Existing v0.187 screens may still display old v0.187 explanatory text such as the released HP and 16-BAR rules outside the new Advancement tab because the patch deliberately avoids rewriting unrelated legacy surfaces during the first implementation pass.

That contradiction is expected to be treated as a BLOCKER by the next Auditor review before promotion.

The purpose of Pass 01 is to verify the new data model and advancement interaction without risking regression across the rest of the app.
