# Protocol 7 v0.188 — Release Audit r001

**Auditor posture:** hostile to continuity errors; permissive toward explicitly identified playtest balance uncertainty.

## Scope reviewed
Current v0.188 rules source, publication-candidate core rules data, Skill registry, Condition registry, VAM reconciliation authority/catalog, purpose-built Gear catalog, application requirements/QA authorities, and new player-facing v0.188 Interactive Rules Guide.

## PASS — no known release-blocking resurrection in these systems
- Ordinary Skill dice stop at d12; Mastery is separate.
- Starting Ability array remains d8/d8/d6/d6/d4/d4.
- Vitality Ritual replaces predecessor Constitution-only starting HP.
- Starting ordinary HP range is 22–26; all-six-blanks exception is 28.
- No generic bonus-die slot.
- Gear, VAM, Advantage, and Mastery remain distinct named sources.
- Advantage adds one d6; Disadvantage removes the smallest Ability die after cancellation.
- Movement is 30 feet per AP, repeatable to 90 feet with all 3 AP; no universal Run multiplier.
- Attack is 1 AP.
- Reaction uses banked AP first and may otherwise borrow at most 1 AP from the next turn.
- Active defense remains in use.
- Normal attack damage is winning margin.
- Armor contributes to appropriate active defense and normally does not also reduce damage.
- Matched Blanks/Dice Tricks are not core v0.188 mechanics.
- VAM field swap is 1 AP for the whole swap; loading into unused BAR is free.

## PLAYER GUIDE AUDIT
The new guide states the core rules above consistently and includes the intended conceptual explanation that the visible dice pool represents identifiable parts of the character and situation. It also includes the expanded Vitality/HP explanation and ritual.

## NON-BLOCKING PLAYTEST UNCERTAINTIES
These are explicitly not reasons to delay v0.188:
- Gear die balance and weapon differentiation are lightly tested.
- Advantage d6 and variable-strength Disadvantage are intentionally asymmetric and require table experience.
- High-level Mastery/VAM pool sizes need actual play.
- No universal critical subsystem exists in this release.
- Some VAM economy/AP interactions remain balance watch items.

## OPEN RELEASE BLOCKER
**The live mobile Vector App is still v0.187.** `app.html` currently routes to the v0.187 character sheet. It must not be relabeled v0.188 until the app implements the v0.188 rules and passes the acceptance matrix.

## RELEASE STATUS
**Rules publication:** PLAYTEST-CANDIDATE / safe to expose as v0.188 rules.

**Full v0.188 product release:** BLOCKED ONLY BY APP SYNCHRONIZATION + final app-focused Auditor pass.

## Auditor instruction
Do not reopen coherent rules merely to polish them before release. Concentrate implementation effort on the app. Any app behavior that contradicts the current rules source is an implementation defect, not permission to restore the predecessor rule.
