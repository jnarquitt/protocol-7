# Protocol 7 v0.188 — Supersession Register r001

**Status:** ACTIVE REGRESSION GUARDRAIL

This is a compact list of known mechanics/product assumptions that v0.188 has deliberately replaced, disabled, or constrained. It exists specifically to stop older material from being copied back into production.

| Topic | v0.188 current direction | Superseded / prohibited resurrection |
|---|---|---|
| Ordinary Skill ceiling | Ordinary Skill progression ends at d12. | Ordinary Skill dice progressing beyond d12. |
| Beyond-d12 expertise | Skill Mastery supplies a separate Mastery die when the Skill is mastered and legal access exists. | Treating Mastery as another ordinary Skill-die step or silently granting it without access. |
| Generic bonuses | Every pool-changing die/removal has a named legal source. | Generic bonus-die slots; unexplained extra dice. |
| Flat modifiers | Protocol 7 uses dice-facing mechanics rather than routine +1/+2 arithmetic. | Reintroducing routine flat numeric bonuses as the normal design language. |
| Gear | Relevant Gear is its own named dice source when rules allow it. | Relabeling Gear dice as Advantage or generic bonus dice. |
| VAM dice | VAM dice occur only when a VAM explicitly grants them and remain VAM-source dice. | Assuming every VAM gives Advantage; treating a VAM die as an anonymous bonus. |
| Advantage / Disadvantage | Separate situational/explicit mechanisms; GM judgment may award them and smart play is encouraged to create Advantage. | Folding A/D into Gear/VAM/Mastery or generic modifiers. |
| Starting HP basis | Six-Ability Vitality Ritual; ordinary result 18 + highest qualifying face; all-six-blanks = 28. | Constitution-only starting HP; fixed 18 starting HP as the v0.188 creation rule; other superseded single-stat formulas. |
| Vitality Ritual | Roll all six assigned Ability dice once; 1–3 blank; highest 4+ sets HP; tied highest permits Vitality Origin choice. | Typed/derived Constitution-only vitality determination. |
| Movement | Spend 1 AP for 30 ft; repeat up to available AP (30/60/90 ft at 1/2/3 AP). | Universal Run action costing all 3 AP; ×2 Run multiplier. |
| Matched Blanks | Disabled/unresolved for core v0.188 unless deliberately reactivated after testing. | Quietly importing unfinished Dice Tricks/matched-blank effects into resolution. |
| Mobile app input | Name is the only expected normal typing field; mechanics use touch controls. | Form-heavy/numeric-keyboard-dependent normal play; required catalog search typing. |
| App rebuild philosophy | Preserve/improve successful prior automation and table usability where compatible with current mechanics. | Treating a clean rebuild as justification to discard useful prior functionality. |

## Usage

Before importing a rule, block of text, function, table, or app behavior from v0.187 or earlier, check this register.

If the imported material conflicts with a row above, do not use it. If a new v0.188 decision supersedes another mechanic, add it here in the same work cycle.

This register does not attempt to contain every current rule. It contains the high-risk regression points most likely to be resurrected from older products.
