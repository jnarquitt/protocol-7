## Explicit incomplete integrations

Pass 02 does **not** claim full synchronization.

### VAM catalog
The inherited app still contains the v0.187 VAM catalog. Pass 02 updates visible capacity to the v0.188 Level-based BAR ceiling but does not yet replace the underlying catalog with the 84-VAM v0.188 candidate catalog or enforce authorization bands against individual VAM choices.

### Ability picker
Core Growth is recorded in the Advancement tab, but Pass 02 deliberately does not mutate the inherited Ability picker. A safe final implementation must derive the character's actual current die and apply the Level 3/5 one-step increase with a d12 ceiling rather than trust a manually entered `from` die.

### Mastery dice in rolls
Pass 02 marks named Mastered Skills visually and shows them on Play, but it does not automatically add Skill Mastery dice to rolls. That behavior also depends on a qualifying Mastery VAM, so automatic roll injection must wait until the rebuilt VAM catalog and Skill identity mapping are integrated together.

### HP writable state
The patch displays the current v0.188 maximum HP but does not yet replace every inherited v0.187 current/max HP storage field. This prevents accidental corruption while the old app data model still assumes CON-derived HP.
