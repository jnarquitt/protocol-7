# Protocol 7 v0.188 — Persona / Action-Corpus Simulation 002

**Scope:** Marcus historical coverage + Maya first-session common actions + Derek tactical procedures + Lena social/investigation mappings. Rules/app inspection, not interactive-browser execution.

## Scenarios exercised

### Marcus — 1241 mounted courier extraction
Actions: ride normally, gallop under missile fire, control a panicked horse, fire bow from horseback, draw sword while mounted, pursue another rider, cross broken terrain.
Findings: ordinary travel should not roll. Hazard/control needs a dedicated Riding Skill. Mounted weapon attacks must retain their weapon Skill. Full chase procedure remains unresolved and is deferred rather than improvised.
Change: add Riding (DEX/WIS/CON). Add basic Riding guidance. Mounted attack remains Archery/melee as appropriate.

### Marcus — 1777 infiltration
Actions: period disguise, ride horse, use musket, reload under pressure, tail a courier, inspect records, force a door.
Findings: Riding gap fixed. Musket→Longarms is sound. Reload lacked AP guidance. Tailing needed explicit Stealth vs Tradecraft distinction. Disguise is supportable by Tradecraft/Deception/Culture without another Skill.
Change: routine action-pressure ready/reload = 1 AP unless overridden; tail guidance added.

### Maya — first session uncertainty
Actions: intimidate guard, determine whether NPC is lying, help ally climb, take cover, resist poison.
Findings: all could be resolved with existing Skills but lacked explicit guidance. Adding more Skills would increase creation burden unnecessarily.
Change: Intimidate→Influence by default; read motives→Perception; Assist grants one Advantage when plausible; cover normally grants Advantage to appropriate active defense; Fortitude default physical resistance.

### Derek — combat exploitation
Actions: stack multiple helpers, stack cover and armor, reload repeatedly, use complete cover, resist sudden trap.
Findings: Assist must cap; cover must not become another Gear die; complete obstruction should make attack impossible when fiction warrants; armor remains Gear; Reflex covers immediate hazard response.
Change: one effective Assist; cover is Advantage rather than Gear; complete cover can prevent attack; generic resistance guidance added.

### Lena — surveillance/social
Actions: shadow suspect through market, maintain cover during surveillance, intimidate with false threat, read immediate body language, interpret documentary evidence.
Findings: existing Skills sufficient with method-based adjudication.
Change: Stealth for remaining unseen; Tradecraft for surveillance pattern/countersurveillance; Influence default intimidation, Deception if lie is primary; Perception for immediate motives, Investigation for accumulated evidence.

## Remaining highest-priority gaps
1. Chase procedure — foot/vehicle/mounted.
2. Defend another person / interception.
3. Surprise/ambush and multiple attackers.
4. Falling, drowning, fire/explosion and sustained environmental harm.
5. Demolitions/explosives Skill/Gear mapping.
6. Suppression application procedure verification.
7. App restoration: advancement, export/import, VAM current-state actions.

## Regression notes
No probability-sensitive mechanic was added in this pass except use of existing Advantage for Assist/cover, so no new dice-math simulation was required. The important design choice was to prefer adjudication mappings over proliferating Skills except where the action represents a genuinely distinct trained discipline (Riding).
