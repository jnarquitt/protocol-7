## Common action corpus — coverage findings

### Clear/current mappings
Notice danger → Perception. Search/investigate → Investigation/Perception. Recall history → History. Persuade → Influence. Deceive → Deception. Sneak/hide → Stealth. Climb/jump/swim → Athletics/Acrobatics. Locks/security → Security. Treat/stabilize → Medicine. Pistol → Sidearms. Rifle/musket/carbine → Longarms. Shotgun → Shotguns. Automatic fire → Automatic Weapons. Knife/sword → Light Melee. Axe/spear → Heavy Melee. Grapple → Grappling. Dodge → Dodge. Drive → Driving. Period knowledge → Culture/History. Team command → Leadership. Improvised weapon → Improvised Weapons.

### Gap fixed this pass
Bow/crossbow had no semantically appropriate Skill and were being forced into Precision Weapons. Add **Archery** as Combat Skill using DEX, DEX, WIS. Bow and Crossbow map to Archery.

### Gaps requiring later focused passes
- Intimidation has no explicit named Skill/procedure. Influence may cover it, but source should say so or add a Skill only if actual play warrants proliferation.
- Read motives has no explicit procedure; likely Perception or Influence depending approach.
- Tailing someone needs explicit Stealth/Tradecraft guidance.
- Cover has narrative/VAM support but the base active-defense interaction needs a compact PLAY-facing procedure.
- Assist ally lacks a concise universal procedure.
- Reload/ready is mostly fictional except VAM Fast Draw; weapon-specific reload expectations are not explicit.
- Generic resist checks (poison, disease, exhaustion) need a consistent Ability/Skill procedure.

## Uncommon corpus — high-value gaps
Disguise/impersonation maps plausibly to Tradecraft/Deception/Culture but needs adjudication guidance. Forgery maps Tradecraft/Security/Culture depending document. Tracking maps Survival. Research maps Investigation/History. Repair maps Engineering. Sabotage maps Engineering/Security. Advanced treatment maps Medicine. Ciphers map Investigation/Computing/Linguistics. Mounted combat has no explicit Riding skill; Driving is not semantically adequate for animal handling. Chases have no unified procedure. Demolitions/explosives lack a clear Skill/equipment family. Pickpocket maps Stealth/Light-fingered action but lacks explicit guidance. Suppression exists as a condition but application procedure needs verification.

## Rare corpus — boundaries exposed
Underwater combat, falling, drowning, environmental exposure, shooting from moving vehicles, extreme range, called shots, defending another person, surprise/ambush and multiple attackers need GM-facing adjudication procedures rather than necessarily new Skills. Dual wielding should not silently create an extra attack/die. Siege/artillery use may require Heavy Weapons plus period Gear. Gear + VAM + Advantage + Mastery stacking is covered structurally by named-source rules but needs app pool-source visibility.
