# Protocol 7 v0.188 — Release Notes (r001)

**Date:** 2026-08-28
**Status:** PLAYTEST — promoted to the public landing page (`index.html` → `app/index.html`).

## What changed for players

- The public app link now launches the single-source v0.188 Vector App
  (`app/`), replacing the r017/r018 iframe/wrapper-chain builds. Those
  remain reachable from the landing page as historical/predecessor
  reference only.
- `app.html` (a stale iframe wrapper pointing at an older nested build)
  now redirects to `app/index.html` instead of serving outdated content.
- Custom and preconfigured Level 1 creation, the Vitality Ritual, Skills
  (My Trained Skills / All / Edit), VAM/BAR selection with Field Swap,
  Gear, a single canonical roll builder with named dice sources, the Play
  screen (AP/movement/Reaction/active defense), Level 1–6 advancement,
  and local save/Export/Import are all live in the promoted build.
- The app header links back to the landing page and out to the current
  Interactive Rules Guide (`rules.html`).

## Release-gate evidence

- 41 of 42 acceptance tests (`P7_v0.188_APPLICATION_ACCEPTANCE_TEST_MATRIX_r001.md`)
  PASS via automated (`app/tests/acceptance-data-model.js`,
  `app/tests/acceptance-functional-logic.js`) and scripted-interactive
  (Playwright, 390×844, real Chrome) evidence. A42 (canon-source
  regression) was closed by human read-through of the app source rather
  than an automated test, by design; that read-through found and fixed a
  real Advancement-gating regression before this promotion.
- No resurrected mechanic found in `app/js/*` on final check (no generic
  bonus-die slot, no old 3-AP/double-distance Run rule).
- Combat/damage is solo/GM-adjudicated (a manual opponent-total input
  feeding `State.resolveAttack`), not yet a full two-Vector opposed-roll
  loop — explicitly a non-blocker for this playtest release per the
  Fast-Track Release Plan.

## Known open item — accepted playtest exception

Manual on-device mobile testing (`app/tests/MANUAL_MOBILE_TESTS.md`) has
not yet been run on a physical phone; only emulated-viewport automation
and scripted interaction exist so far. The designer accepted shipping
this playtest build without that pass, consistent with the Fast-Track
Release Plan's instruction not to delay a playtest for confirmation that
real table/device use can just as well surface. Run the manual script at
the first opportunity and correct `app/tests/ACCEPTANCE_STATUS.md` if any
item fails on a real device.

## Predecessor builds

v0.187 promoted materials and the v0.188 r017/r018 wrapper-chain builds
remain in the repository and linked from the landing page as historical
reference, per the no-deletion/history-preservation practice in
`00_READ_FIRST_PROTOCOL_7_AUTHORITY_MAP.md`.
