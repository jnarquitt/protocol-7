# P7-AP01-M02 — The Winter Relay
## Playtest Simulation Report r001

Eight simulation profiles were run against the draft: investigative/experienced, combat-forward, cautious/low-initiative, four-hour convention, lateral-thinking, bad-luck, high-Exposure, and anti-Aletheia/Covenant-sympathetic.

## Main findings

The strongest structure is experiential: players use Mercer’s relay method before learning it is the Carrier. The false victory must feel real but last only briefly. Covenant works best when it helps save today’s lives before opposing long-term propagation. Technical radio knowledge should stay character-facing; player decisions should concern verification, route, time, redundancy, trust, and historical footprint.

## Corrections incorporated

- Immediate message success no longer reads as the end of the adventure.
- Multiple useful jobs prevent cautious groups from waiting for Mercer to assign a solution.
- Failed rolls raise cost instead of collapsing the only communications route.
- Player-created propagation routes are explicitly valid.
- Siding with Covenant is a valid outcome, not a campaign derailment.
- High-Exposure future-tech use works mechanically but changes opposition priorities.
- Convention pacing merges repair/reconstruction when needed and protects the final verification/debrief.

## Recommendation

P7-AP01-M02 — The Winter Relay r001: PLAYTEST-READY.

No frozen Protocol 7 v0.187 mechanic was changed.
