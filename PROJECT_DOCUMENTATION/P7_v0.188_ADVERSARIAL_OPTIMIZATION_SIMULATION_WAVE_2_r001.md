# Protocol 7 v0.188 — Adversarial / Optimization Simulation Wave 2 r001

**Status:** AMBER-GREEN — architecture holds; two rules clarifications required before promotion

## Scope

This wave stress-tests the v0.188 advancement proposal under deliberately optimizing and adversarial play:

- maximum Skill Mastery investment;
- low-BAR utility stacking;
- VAM support-chain stacking;
- Strength/HP optimization;
- deliberately inefficient advancement choices;
- Mastery-capable peer enemies;
- five-die versus six-die Protocol Dice / Dice Tricks pattern frequency;
- Level 6 30-BAR loadout saturation.

## 1. Mastery optimization — PASS WITH CEILING RULE

Representative comparison:

Five-die veteran pool: d10, d8, d8, d6, d4.
- Expected Protocol score: **15.90**
- DC 15+: **58.3%**
- DC 18+: **41.1%**
- DC 20+: **30.0%**
- DC 24+: **12.6%**

Comparable six-die pool adding a d10 Skill Mastery Die: d10, d10, d8, d8, d6, d4.
- Expected score: **20.80**
- DC 15+: **79.5%**
- DC 18+: **67.0%**
- DC 20+: **57.1%**
- DC 24+: **36.6%**

A still-higher d12 Mastery specialist reaches an expected score of **21.90** and DC 20 about **62.3%**.

Verdict: the sixth die is a major, visible veteran reward. It is powerful enough to justify a 7–9 BAR commitment but not intrinsically broken.

**Required rule:** routine pools should not grow beyond six dice through Feature stacking. Later progression should alter access/effects, not add seventh/eighth dice.

## 2. Peer Mastery enemy — PASS

Against an otherwise comparable five-die opponent, the six-die d10-Mastery pool wins an opposed score approximately:
- **67.0% win**
- **3.6% tie**
- **29.5% loss**

This is a strong peer-elite signal without requiring inflated HP. Enemy Mastery should therefore be reserved for named/elite opposition and communicated through fiction or observed capability rather than applied broadly to ordinary historical adversaries.

## 3. Dice Tricks / raw-face pattern pressure — AMBER

Using the representative pools above and treating Dice Tricks as raw-face patterns:

Five dice:
- at least one repeated face: **76.6%**
- triple-or-better: **12.4%**
- four-of-a-kind-or-better: **0.9%**
- contains 1, 2, and 3 together: **12.4%**

Six dice:
- at least one repeated face: **88.3%**
- triple-or-better: **20.2%**
- four-of-a-kind-or-better: **2.0%**
- contains 1, 2, and 3 together: **17.3%**

If every ordinary pair is a triggered Dice Trick, both five- and six-die play become too noisy, and Mastery makes that substantially worse.

**Recommendation:** Protocol Dice Tricks should continue to privilege rarer/meaningful patterns rather than treating any pair as a full-strength special event. Six-die Mastery naturally increases spectacular-pattern frequency, which is desirable if the trigger table is calibrated around that fact.

## 4. VAM support-chain stacking — AMBER-RED UNTIL CLARIFIED

Potential combinations include Command Link (d6), Coordination Mesh (d4), Distributed Command (d4), equipment dice, situational dice, and a Skill Mastery Die.

Without a stacking rule, optimized teams can accidentally exceed the intended six-die ceiling even when no single VAM is individually problematic.

### Proposed simulation rule

**One Feature Die per roll:** a roll may receive no more than one bonus die whose source is a VAM/Feature, except the Skill Mastery Die when a Mastery-capable VAM explicitly grants it.

Thus the intended upper structure is normally:
- Skill die;
- three Ability dice;
- one ordinary primary Gear/Weapon/Situational die as permitted by the base rules;
- one Skill Mastery Die when accessed.

Other VAMs should alter permissions, timing, AP, reactions, information, positioning, or choose/improve the single permitted Feature contribution rather than stacking additional dice indefinitely.

Exact terminology must be reconciled with the Protocol Dice Engine dice-pool grammar before canonization.

## 5. Low-BAR stacking at 30 BAR — PASS

Optimized Level 6 characters can load many 1–4 BAR evergreen utilities, sometimes approaching 9–12 distinct VAMs if they avoid expensive systems.

This did **not** automatically produce excessive roll power because most low-BAR VAMs remove narrow friction, grant small permissions, or alter specific procedures rather than add large dice.

The tradeoff remains meaningful: such a character becomes exceptionally broad but gives up 8–12 BAR Mastery/capstone systems.

Recommendation: retain abundant low-BAR VAMs. They are a feature of the system and keep Level 1 modules relevant at Level 6.

## 6. 30 BAR saturation — PASS

Thirty BAR does not mean 'load everything.' A representative Level 6 Mastery/capstone configuration can spend:
- 11–12 BAR capstone;
- 7–9 BAR Mastery access;
- leaving roughly 9–12 BAR for supporting modules.

A Level 6 Vector can therefore run an extremely sophisticated configuration, but still cannot simultaneously carry every desirable specialist system.

Verdict: **16/18/21/24/27/30 remains the preferred BAR curve for Wave 3.**

## 7. Strength / HP optimization — AMBER

Testing the proposed fixed-18 starting HP plus half-current-STR-maximum HP per new Protocol 7 Level:

If STR never changes:
- d4 finishes Level 6 at 28 HP
- d6 at 33 HP
- d8 at 38 HP

If a character deliberately uses both proposed Core Growth opportunities to raise STR, the exact final total depends on whether the Ability step occurs before or after that level's HP award. Under the cleaner 'HP first, then Core Growth' sequence, a starting d4 that raises STR at Levels 3 and 5 reaches approximately 32 HP; a starting d8 that raises STR toward d12 reaches approximately 42 HP.

This is a meaningful optimization advantage but not yet obviously dominant.

### Required clarification
Use a fixed advancement order so players cannot manipulate the same Level's HP award:
1. gain level HP using the STR die held at the end of the previous level;
2. allocate Skill Ranks;
3. apply BAR/authorization changes;
4. make any Core Growth choice.

This means an STR increase benefits **future** levels only and never retroactively changes prior HP.

Wave 3 must compare this model directly against fixed +3 HP per level in combat simulations.

## 8. Deliberately inefficient build — PASS

A character who spreads Skill Ranks poorly, takes broad low-BAR VAMs, and declines Mastery remains playable but clearly less dominant in their best rolls than an optimized specialist.

The BAR/VAM layer softens bad Skill choices by providing permissions, information, movement, support, and utility rather than only numeric bonuses.

No trap choice was severe enough in this wave to justify automatic respec rules, though the app should make Skill breakpoints and VAM authorization requirements highly visible.

## 9. Level 2 'quiet level' — STILL AMBER

Level 2 provides +4 Skill Ranks, +2 BAR, and Advanced I authorization. If a player's +4 ranks fail to cross a Skill breakpoint and their chosen Advanced I VAM is subtle, the level can feel less dramatic than Levels 3–6.

This is not a mathematical failure. It is a presentation/reward-cadence issue.

Recommendation: each Level 2 advancement package should also include a **meaningful horizontal authorization/reward** (contact, mission authority, resource access, safehouse, specialized equipment clearance, etc.) rather than increasing numerical power further.

## Wave 2 verdict

**AMBER-GREEN.**

The main architecture survives deliberate optimization:
- BAR 16/18/21/24/27/30 works;
- Level 4 Skill Mastery works;
- 7–9 BAR is an appropriate first Mastery cost range;
- non-Mastery breadth remains viable;
- 30 BAR does not erase loadout choice;
- peer Mastery creates the desired elite-opposition feel.

Two issues must be resolved before promotion:

1. **Feature-die stacking / six-die ceiling must become an explicit Engine rule or clearly defined Protocol 7 implementation rule.**
2. **HP advancement timing and the Strength-based model must receive direct combat comparison against fixed HP growth.**
