# Protocol 7 v0.188 — Level 1 VAM Preset Rebuild r001

**Status:** SIMULATION BASELINE — not player-facing canon

These presets rebuild the existing recommended Paths as legal Level 1 Standard packages under the proposed v0.188 16-BAR starting capacity. Paths remain recommendations, not classes. Players may freely build custom legal Standard loadouts.

## Design result

All fourteen existing Path identities can be preserved at Level 1 without using later-authorization VAMs. Several old presets intentionally lose veteran capabilities such as Deep Cover, Counterintelligence, Field Fabrication, Command Link, Temporal Intuition, Breach Window, Motion Prediction, and Precision Interdiction at character creation. Those become meaningful advancement targets instead of starting entitlements.

## Findings

1. **16 starting BAR remains viable.** Starting identity does not require increasing Level 1 capacity.
2. **Advancement becomes more visible.** Several old starting-package signatures become L2–L4 unlocks, creating real anticipation.
3. **Low-BAR VAMs matter.** The rebuilt 1–3 BAR foundation permits 7–10-module starting packages without making all characters mechanically identical.
4. **Command requires special attention.** Command Link's placement should be simulation-tested because it is both highly thematic and potentially defining enough to deserve early access.
5. **Medic is healthy at 15 BAR.** Leaving 1 BAR intentionally unused is acceptable and may teach that filling every BAR is not mandatory.
6. **Preset identity remains distinct despite shared utility modules.** The next simulation should measure whether repeated low-BAR utilities make packages feel too samey in actual play.

## Next step

Use these Level 1 baselines in persistent Level 1–6 simulations. Each test character should retain a recognizable starting identity while adding Skill Ranks, HP, Ability/Core Growth, BAR, authorization tiers, and optional Skill Mastery.
