# Protocol 7 v0.188 — Skill Die Cap & Mastery Supersession r001

**Status:** CURRENT v0.188 CANDIDATE AUTHORITY
**Date:** 2026-08-23

## Decision

For **Protocol 7 v0.188**, the ordinary Skill die progression is capped at **d12**.

The inherited v0.187 post-d12 progression that previously produced additional Skill dice at ranks 15, 21, 28, 36, and 45 is superseded for v0.188.

### v0.188 ordinary Skill progression

- Rank 0 → d4
- Rank 1 → d6
- Rank 3 → d8
- Rank 6 → d10
- Rank 10+ → d12

Ranks above 10 may still be tracked if needed for advancement history or future design, but they do **not** create d12+d4, d12+d6, d12+d8, d12+d10, or d12+d12 ordinary Skill dice in v0.188.

## Why

The new **Skill Mastery** system replaces the need for ordinary Skill progression beyond d12.

The intended hierarchy is now:

- ordinary learned competence advances from d4 to d12;
- d12 represents the ceiling of ordinary Skill expertise;
- veteran distinction beyond that ceiling is represented by Skill Mastery;
- an appropriate Mastery-capable VAM determines when the Mastery Die may enter the roll;
- routine pool size stays bounded, transparent, and easy to read at the table.

This prevents two separate systems from both representing post-expert Skill growth.

## Mastery interaction

A Mastered Skill's **Mastery Die equals its current ordinary Skill die**.

Therefore a rank-10+ Mastered Skill has:

- ordinary Skill die: d12;
- Mastery Die: d12 when legally accessed.

Only one Mastery Die belonging to the Skill currently being rolled may enter the pool.

## Supersession

For v0.188, this decision supersedes any inherited or historical rule text that lists post-d12 Skill progression at ranks 15, 21, 28, 36, or 45.

The public v0.187 release remains unchanged until coordinated v0.188 promotion.

## App/Data consequence

The v0.188 clean-rebuild app must derive Skill dice using only the five ordinary breakpoints above. Post-rank-10 growth must never silently add another ordinary Skill die.

The clean app's Skill Mastery implementation becomes the only routine mechanism for adding a second Skill-related die beyond the d12 ordinary ceiling.
